# 课程表 CHD (Course Schedule for CHD)

一款专为长安大学（CHD）学生设计的课程表 Android 应用。登录学校统一身份认证，自动把教务系统的课表搬到手机上——离线可查、可编辑、可同步到系统日历。

## 下载与安装

### 系统要求

- Android 9（API 28）及以上
- arm64-v8a 架构（绝大多数现代安卓手机）
- 建议将系统 WebView（Android System WebView）保持最新（可在应用商店更新），过旧的 WebView 可能影响教务系统登录

### 下载

前往本仓库的 [Releases](https://github.com/code-cycler/course_schedule_for_CHD/releases) 页面，下载最新版 APK（如 `CHD_v2.4_debug_20260901_194503.apk`）。

### 安装步骤

1. 下载 APK 文件到手机
2. 点击安装；系统提示「未知来源 / 安装未知应用」时，允许本来源安装（各品牌手机路径略有不同，一般在系统设置的「应用管理 → 安装未知应用」中开启）
3. 安装完成后打开应用

> **首次使用前提**：手机需连接校园网或 VPN（教务系统仅校内网络可访问）。

## 为什么需要这个 App？——网络渲染兼容性

> 本章保留原「技术详解」中网络渲染兼容性的核心内容（完整技术细节见 [docs/DESIGN.md](docs/DESIGN.md)）。

### 问题背景

长安大学教务系统（`bkjw.chd.edu.cn`，beangle 框架）的课表网页有四个「疑难杂症」：

1. **JavaScript 依赖重** — 页面依赖 jQuery、beangle (bg)、underscore 等多个 JS 库
2. **动态渲染** — 课表数据不在原始 HTML 里，而是由页面 JS 运行后才生成
3. **WebView 兼容性差** — Android 系统 WebView 无法完整加载教务系统的外部 JS 资源，直接打开课表页会白屏；手机浏览器同样打不开或显示不全
4. **CAS 单点登录** — 登录入口在统一身份认证（`ids.chd.edu.cn`），会话 Cookie 需跨域带到教务系统

因此「直接抓接口」或「直接开网页」都行不通——这就是本 App 要解决的网络渲染兼容性问题。

### 解决思路：脚本环境模拟注入

既然 WebView 能完成 CAS 登录，那就让 WebView 把课表**渲染出来**，再把渲染后的 HTML 抠出来自己解析：

- **拦截注入**：拦截教务系统首页 / 课表页的 HTML 请求（CAS 登录页不拦截），在返回给 WebView 之前，注入一套自写的 JavaScript 环境模拟——假 jQuery、假 beangle (bg)、假 underscore，以及课表容器 `CourseTable` / `TaskActivity`
- **骗过页面**：教务页面自己的 JS 以为依赖库都在，正常执行，课表数据被完整渲染进页面
- **动态等待**：轮询检测课表数据是否渲染就绪（而非固定等待几秒），就绪后抠出整页 HTML
- **本地解析**：渲染后的 HTML 交给解析器，提取教师、教室、53 位周数位图、星期节次，转成课程数据存入本地数据库

### 登录抓取流程

```
用户在 WebView 登录 CAS
   │
   ▼ 拦截教务首页 HTML → 注入模拟脚本
加载首页 → 提取「本周为第 N 教学周」
   │
   ▼ 拦截课表页 HTML → 注入模拟脚本
加载课表页 → 轮询等待渲染就绪 → 抠出渲染后 HTML
   │
   ▼
解析课程数据（教师/教室/周次位图/星期节次）→ 存入本地数据库
   │
   ▼
展示课表（离线可查）
```

## 常见问题

**Q: 登录失败怎么办？**
A: 请检查网络连接，确保手机在校园网或 VPN 环境下能访问学校教务系统。如仍有问题，可通过设置抽屉导出日志排查。

**Q: 手机浏览器能直接打开教务系统课表吗？**
A: 少数品牌不行或显示不全——教务课表页重度依赖 JavaScript 动态渲染，且外部 JS 资源加载不全时会白屏（见上文「为什么需要这个 App」）。本 App 通过脚本环境模拟注入解决了这个问题。

**Q: 课表显示不完整 / 识别不对？**
A: 尝试重新登录同步最新数据；个别课程解析不对时，可在课程详情弹窗点「报告错误」导出报告反馈。

**Q: 如何编辑课程信息？**
A: 点击课程卡片 → 详情弹窗 → 编辑课程，可修改教师、教室、周次和节次，也可添加 / 删除时段。

**Q: 日历同步不生效？**
A: 请确保已授予日历读写权限，并在设置抽屉中确认日历同步已开启。

**Q: 应用崩溃了怎么办？**
A: 应用会在下次启动时自动弹出崩溃报告对话框，可导出日志文件进行排查。

**Q: 支持哪些设备？**
A: arm64-v8a 架构的 Android 设备（大多数现代手机），最低 Android 9。
