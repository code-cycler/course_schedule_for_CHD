## 背景（出题依据，已核实的代码事实）

本 feature 打包三需求（入口校准已确认框架）：

- **A. 深色导出 bug**：`ExportableScheduleGrid.kt:72` 根 Column 无背景（PNG 透明）+ 文字/边框色取自 `colorScheme.onSurface/outlineVariant`（深色模式下变浅白），且 `MainActivity.kt:36` 唯一主题包裹点跟随系统 → 深色下导出即异常。
- **B. 「多线程优化渲染」**：实测瓶颈在主线程数据计算——`ScheduleViewModel.kt:192/687`（coursesByWeek 全周遍历）、`:171/681`（冲突预计算 + DataStore JSON 写盘）、`ScheduleImageExporter.kt:99`（PNG compress）全在 Main 执行，全 ViewModel 无一处 `withContext`；Compose 侧无 key()/@Immutable 优化。
- **C. UI/UX 优化**：范围已圈定 = 交互细节 + 无障碍文案 + 动画/现代化 + 新增细节功能（开放）；「外观个性化（深色手动开关等）」未被勾选。
