## 目标与受众

**受众**：长安大学学生（本 App 用户，中文为主）。

**三目标**（交付顺序 A → B → C，W00 第 1/2 条）：
- **A. 修复深色模式下课表分享图颜色异常**（P0 确定性 bug）：导出图拥有完整背景与自洽配色，且**配色跟随系统深浅模式**（W00 补充声明）——深色系统下导出深色皮肤图，浅色系统下导出浅色皮肤图。
- **B. 消除主线程阻塞**：启动加载课表、切换周次、导出图片三个场景中，数据计算与 IO 全部移出主线程；辅以 Compose 重组优化（key/remember/@Immutable）。
- **C. UI/UX 现代化**：交互细节修缮 + 无障碍与文案统一 + 克制的 Material 3 动效 + 用户提案的细节功能（W01 征集中）。

## 范围（做什么；明确不做什么）

**做**：
- A：`ExportableScheduleGrid` 导出链路的配色重构（显式主题包裹 + 背景填充，跟随系统深浅，**仅导出链路用固定深浅两套配色**，App 界面照旧动态取色——W01 Q2-B）。
- B：`ScheduleViewModel`/`CourseRepositoryImpl` 的重计算移后台线程（withContext/Dispatchers）；`ScheduleImageExporter` 的 PNG 压缩移 IO；Compose 重组优化。
- C：C1–C6 修缮清单（见验收标准）。
- D：启动静默同步（ON_RESUME 后台 diff + 差异确认入库，见验收 D1–D5；交付顺序 A→B→C→D）。

**明确不做**（W00 第 5/6/10/11/12 条 + W01）：
- 不做外观个性化（App 内深色手动开关、动态取色开关等设置项）——不在本批。
- 不重写渲染引擎、不把课表网格整体重构为自绘 Canvas。
- 不新增大型第三方库（动画/性能/UI 用 Compose 与协程官方能力）。
- 不触碰解析/位图/Room 正确性逻辑（`ScheduleHtmlParser`、`Course.isWeekInRange`、位图偏移逻辑零改动；静默同步若纳入也只复用现有解析链路）。
- 不建 Macrobenchmark/Baseline Profile 模块。
- 不做桌面小部件（W01 Q1-E 用户勾选但明确「放 TODO」，拆出本批为独立 feature 后设计）。

## 核心场景

1. **分享（A）**：深色系统模式下点顶栏分享按钮 → 导出 PNG 有完整深色背景、深底浅字对比度正常；浅色模式同理（浅底深字）；任何查看器中不出现透明底导致的黑底/花字。
2. **启动加载（B）**：进入课表页，Room 读取、coursesByWeek 全周索引、冲突预计算在后台线程执行，主线程仅接收结果更新 UI。
3. **切换周次（B）**：HorizontalPager 滑动/点击切周，冲突缓存读取与周数据组装不阻塞主线程。
4. **导出过程（B）**：GraphicsLayer 录制后的 PNG 压缩与写盘在 IO 线程，导出期间 UI 可交互。
5. **日常使用（C）**：动效克制流畅、文案语言统一、TalkBack 可读课程卡（W01 确认细节后补充场景）。

## 风险与约束

- **数据链路红线**：性能优化只动线程调度与 UI 层；位图偏移（DESIGN.md §6，v96 反复修正）与多教室解析（v120）刚稳定，零触碰。
- **动效回归前科**：`ScheduleGrid.kt:41` 注释记录 v42 曾移除 AnimatedVisibility（性能问题）；动效设计须以「不拖慢网格滚动」为前提。
- **动态取色已裁决**（W01 Q2-B）：仅导出链路用**固定深浅两套配色**，App 界面照旧动态取色——分享图跨设备颜色一致。
- **静默同步（D）的风险**：复用现有解析入库链路（不改解析本身，不违背红线），但课程差异检测（diff）是新逻辑；「假更新覆盖好数据」（教务改版/解析异常）以「先展示后确认」防御（ADR-0007）。**更新检测覆盖率取决于 cookie 存活窗口**（CAS session 有时效，v113 只修了「重启不丢」）——用户冷启动时 cookie 多半已过期，静默检查多为 no-op，功能实际只在「近期登录过」的窗口内有效（grill-W01 Q2 裁决：接受限制 + 预期管理，见 OPEN-DECISIONS）。
- **三批改动共享接触面**：A/B/C 都动 `ScheduleScreen` 及周边，分阶段交付（A→B→C）防互相踩踏。
- **跟随系统的深色分享图**：深色图在浅色环境查看时观感由用户接受（用户拍板「跟随系统」）；实现须保证深色图自身深底浅字完整自洽，不依赖查看器背景。
