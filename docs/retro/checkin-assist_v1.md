## 学到什么（可复用）

- 反射调系统 API 必须**解包 `InvocationTargetException`**，否则真实异常类型被吞。
- 系统/第三方 API 方法名**别信网传**，用 `javap -classpath android.jar` 查 jar 才是真相。
- **真机早测**——权限/定位/通知监听相关的功能，模拟器和单测拦不住机型差异。
- **增量构建不可信**——真机安装前 `clean assembleDebug` + 校验 APK 完整性（`unzip -l`）。
- 荣耀/Honor 的 NLS/USB 安装/后台保活是系统层坑，需用户手动操作，应用层只能引导。
- 个人项目里「地图选点」往往不如「采集真实位置」——更准且免 Key/免坐标转换。
- 把边界（不做什么）和合规风险在动手前用 grilling 敲死，比事后删代码省事。
- 重大方案反转要落 ADR（哪怕反转两次），未来读者才知道为什么。
